# Building on Windows 10 with Visual Studio Code

## 1. Install Java

Minecraft Java 26.2 and this project require **Java 25**.

1. Download the Windows x64 installer for [Microsoft Build of OpenJDK 25](https://learn.microsoft.com/java/openjdk/download).
2. Run the MSI installer.
3. Enable the options that configure `JAVA_HOME` and add Java to `PATH`, if shown.
4. Restart PowerShell and Visual Studio Code.

Verify the installation:

```powershell
java -version
javac -version
```

Both commands must report version 25. If another version is active, configure the current PowerShell session before building:

```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-25.0.x"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
```

Replace `jdk-25.0.x` with the exact name of the installed directory.

## 2. Set up Visual Studio Code

Install these Visual Studio Code extensions:

- **Extension Pack for Java**, published by Microsoft.
- **Gradle for Java**, published by Microsoft.

Extract the source into a short, writable path, for example:

```text
C:\Projects\PassableFoliageForked
```

Extract it into an empty directory. Do not overwrite an older project copy, because obsolete generated resources may remain and cause duplicate-file errors.

Do not build directly inside the ZIP, under `Program Files`, or in a synchronized directory that may lock temporary files.

In Visual Studio Code, select **File > Open Folder** and open the directory containing `build.gradle` and `gradlew.bat`. Wait for the Gradle project import to finish.

## 3. Build the mod

Open **Terminal > New Terminal** and run:

```powershell
.\gradlew.bat --version
.\gradlew.bat clean build
```

On the first run, the wrapper downloads Gradle 9.7.0 and the required dependencies. The configured SHA-256 checksum is used to verify the Gradle distribution.

A successful build ends with:

```text
BUILD SUCCESSFUL
```

Generated files:

```text
build\libs\PassableFoliage-mc26.2-Fabric-26.2.0.jar
build\libs\PassableFoliage-mc26.2-Fabric-26.2.0-sources.jar
```

The first file is the mod. The second is the source archive generated by Gradle.

## 4. Run development environments

Start a development client:

```powershell
.\gradlew.bat runClient
```

Start a development server:

```powershell
.\gradlew.bat runServer
```

Regenerate data files:

```powershell
.\gradlew.bat runDatagen
```

Review changes under `src\generated\resources` before committing generated files.

## 5. Troubleshooting

### Java 25 is not being used

Check which JDK is active:

```powershell
java -version
echo $env:JAVA_HOME
.\gradlew.bat --version
```

Restart Visual Studio Code after changing `JAVA_HOME`.

### Dependency downloads fail

Confirm HTTPS access to:

- `services.gradle.org`
- `maven.fabricmc.net`
- `repo.maven.apache.org`
- Mojang and Minecraft download services

Then retry with:

```powershell
.\gradlew.bat --refresh-dependencies clean build
```

### Duplicate `en_us.json` resource

This usually means the source was extracted over an older project directory. List every matching file:

```powershell
Get-ChildItem .\src -Recurse -Filter en_us.json | Select-Object FullName
```

Keep `src\main\resources\assets\passablefoliage\lang\en_us.json` and remove the obsolete copy under `src\generated\resources`.

### A file is locked during `clean`

Close any running `runClient` instance and stop older terminals. Restart Visual Studio Code if the file remains locked.

## 6. Install the result

Copy only the main JAR to the `mods` directory of the Minecraft 26.2 instance. Also install:

- Fabric Loader 0.19.3 or newer, or a Quilt Loader version compatible with Minecraft 26.2.
- Fabric API 0.158.0 or newer for Minecraft 26.2.

Client and server installations must use compatible versions of the mod and Fabric API.
